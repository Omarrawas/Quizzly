# 📱 تطبيق كويزلي | Quizzly App

تطبيق **كويزلي (Quizzly)** هو منصة تعليمية وتفاعلية متكاملة ومتطورة، تم بناؤها باستخدام إطار عمل **Flutter** ولغة **Dart**، وربطها بالكامل مع **Firebase (Firestore, Authentication, Remote Config)** لتقديم تجربة دراسة استثنائية وبديهية ومحفزة للطلاب.

---

## 🚀 الميزات الرئيسية للتطبيق (Features)

### 1. 🎓 إدارة ودراسة المواد والأسئلة
* **أنماط دراسة متعددة**: وضع الاختبار، وضع التصفح، ووضع الحفظ الذكي.
* **البحث المتقدم**: تصفية الأسئلة والبحث فيها وعرض الشروحات المفصلة المدعمة بصور ومقاطع فيديو.
* **إدارة التحميلات للفيديو والمحتوى**: إمكانية تحميل الفيديوهات والشروحات للعمل **بلا اتصال بالإنترنت (Offline Mode)** تماماً.
* **ترتيب المواد الذكي**: ترتيب متقدم حسب الأحدث، آخر مادة تم فتحها، أو ترتيب يدوي مخصص يدعم السحب والإفلات.

### 2. 💳 نظام المحفظة والاعتمادات (Quizzly Wallet System)
* **شحن الرصيد**: شحن الحساب عن طريق رموز التفعيل المطبوعة أو شراء الأكواد مباشرة.
* **تفعيل المواد**: شراء وتفعيل المواد الدراسية المدفوعة باستخدام رصيد المحفظة عبر عمليات Firestore Transaction آمنة ومحمية من التلاعب.
* **الشراء الذكي (شام كاش)**: كرت شراء مخصص يوجه الطالب للتواصل الفوري لشحن حسابه عبر بوت تلغرام أو واتساب معتمد.

### 3. 🛠️ لوحة تحكم الأدمن الشاملة (Admin Workspace)
* **إدارة المستخدمين والأجهزة**: متابعة الطلاب، التحقق من عدد الأجهزة المفعلة لكل حساب وتصفير الأجهزة عند الحاجة.
* **توليد وإدارة الأكواد**: إنتاج أكواد تفعيل رصيد بكميات وتصديرها كملفات Excel أو PDF.
* **ضبط وسائل التواصل وبوت الدعم الفني**: واجهة مرنة للأدمن لتفعيل أو إلغاء قنوات الدعم والتواصل ومزامنتها لحظياً لدى الطلاب.
* **إحصائيات مالية وتحليلية**: رسوم بيانية توضح معدلات الشحن والتفعيل ونشاط الطلاب.

### 4. 📳 المزامنة والعمل بلا إنترنت (Robust Offline Architecture)
* تطبيق كويزلي مجهز بالكامل للعمل بفعالية عالية في وضع **الأوفلاين**:
  * حفظ الكاش المحلي لبيانات Firestore لضمان استمرار تصفح المناهج.
  * تحميل المحتوى التفاعلي وملفات الفيديو محلياً.
  * التحقق الذكي من التحديثات لمزامنة أحدث التغييرات بمجرد توفر الاتصال.

## 📂 الهيكلية البرمجية للمشروع (Architecture)
يتبع المشروع معايير **Clean Architecture** مع **Feature-First Directory Structure** لتحقيق أقصى قدر من قابلية الصيانة والتوسع:
* **`core/`**: يحتوي على القواعد الأساسية مثل الثيمات (Theme)، الألوان (AppColors)، والمساعدات العامة.
* **`features/auth/`**: الخدمات الخاصة بالتحقق من الهوية، تسجيل الدخول، والمزامنة الأمنية للأجهزة البصرية والفريدة.
* **`features/home/`**: الواجهة الرئيسية وشريط التنقل والتحديثات التلقائية.
* **`features/admin/`**: أدوات الإدارة، توليد الأكواد، الإحصائيات، وبطاقات الدعم والشبكات الاجتماعية.
* **`features/settings/`**: إعدادات الحساب، تفضيلات الدراسة، إدارة الأجهزة، والمحفظة الرقمية.

## 🛠️ متطلبات التشغيل والتطوير (Getting Started)

1. **تثبيت Flutter SDK**: (الإصدار 3.11.1 أو أحدث).
2. **إعداد البيئة**: تأكد من وجود ملفات إعداد Firebase لـ Android و Windows.
3. **تثبيت الحزم**:
   ```bash
   flutter pub get
   ```
4. **تشغيل التطبيق**:
   ```bash
   flutter run
   ```
